# Environment secrets (README)

Place your credential files in the `.env/` folder (for example `.env.local`) and do NOT commit them to the repository.

Suggested usage:
- Create a file like `.env.local` inside the `.env/` folder with key=value pairs.
- Load them in your test runner or script as needed.

Example `.env.local`:
```
USERNAME=your-username
PASSWORD=your-password
```

The `.env/` folder is ignored by the repository to prevent accidental commits of secrets.
This README is tracked so collaborators can see how to store credentials safely.
